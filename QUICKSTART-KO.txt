BELLEMYUNAIL 관리자 빠른 설정

1) ZIP 전체를 tambleofficial/bellemyunail1에 덮어쓰기 -> main push
2) GitHub > Settings > Developer settings > GitHub Apps > New GitHub App
3) Homepage = 현재 workers.dev 주소
4) Callback = 현재 workers.dev 주소 + /admin/auth/callback
5) Webhook Active OFF
6) Repository permissions > Contents = Read and write
7) Install App > Only select repositories > bellemyunail1
8) Client ID / Client Secret / Private Key 준비
9) https://api.github.com/users/내GitHub아이디 에서 숫자 id 확인
10) Cloudflare bellemyunail > Settings > Variables and Secrets에 아래 4개 Secret 추가
    GITHUB_APP_CLIENT_ID
    GITHUB_APP_CLIENT_SECRET
    GITHUB_APP_PRIVATE_KEY
    ADMIN_GITHUB_USER_ID
11) Worker 재배포
12) /admin/ 접속 -> GitHub로 로그인

R2 / Zero Trust / Access / PAT / 카드 등록 사용 안 함.
자세한 내용: SETUP-GITHUB-APP-KO.md
