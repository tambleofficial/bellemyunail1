주황 점선은 문구, 파란 점선은 사진입니다. 클릭하는 즉시 이 영역에 해당 문구 또는 사진 편집기가 열립니다.

문구클릭 → 오른쪽 입력창 → 즉시 미리보기

문구

입력 즉시 미리보기에 반영됩니다. 실제 공개 사이트는 아래 ‘전체 저장 및 배포’를 눌러야 변경됩니다.

사진을 선택하면 최대 폭 1920px WebP로 변환하고 EXIF/GPS 정보를 제거합니다.
변경사항 없음 문구와 사진을 여러 개 수정한 뒤 한 번에 저장할 수 있습니다.
