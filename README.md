# BELLEMYU NAIL

청주 네일 키워드를 중심으로 구성한 Cloudflare Workers Static Assets + R2 사이트입니다.

## 구성

- `/` Home
- `/nail-design/` Nail Design
- `/process/` Process
- `/portfolio/` Portfolio
- `/visit/` Visit
- `/faq/` FAQ
- `/admin/` Cloudflare Access 보호 관리자
- `/admin/api/*` 관리자 API
- `/media/*` R2 이미지 출력
- `/api/media-manifest` 공개 이미지 버전 manifest
- `/sitemap.xml` 동적 sitemap
- `/robots.txt` 동적 robots

자세한 배포 절차는 `SETUP-KO.md`를 확인하세요.
